# 全局插件

来源：[`src/lib/builtin-plugin-catalog.ts`](../src/lib/builtin-plugin-catalog.ts) 的 `GLOBAL_PLUGIN_CATALOG`（决策清单「做」）。

- **策略**：平台默认能力目录；插件页「全局」Tab 展示，多数无用户开关。
- **实现层**：本文件为规格说明；**不等于**已全部实现。与扩展/`tb-*` 有重叠的在「Lantern Harness 映射」注明。
- **扩展插件**（可开关，另见 `plugins.ts`）：`cases` / `prompts` / `knowledgeLib` / `requirements` / `templates`（侧栏库入口与内容根）以及 `caseGen` / `promptGen` / `knowledgeGen` / `knowledge` / `memory` / `todos` / `tasks` / `reports` / `testStats` / `caseExec` / `dashboard` / `pluginDev` — 对应 `lh-kb`、`lh-memory`、`lh-project-docs`、`lh-todos`、`lh-tasks`、`lh-reports`、`lh-stats` 等，不在本全局清单逐条重复产品开关逻辑。`dashboard` 只在前端聚合前三个接口的数据，没有独立的 `lh-plugins` 中间件与数据目录。

## session-checkpoint-policy

- **分类**：会话 / 存储
- **作用**：会话检查点策略。
- **状态**：部分就绪（含恢复 UI）
- **Lantern Harness 映射**：[`session-persist.mjs`](../lh-plugins/session-persist.mjs) → `.local/checkpoints/<sessionId>-latest.json`；侧栏「从检查点恢复」；`GET /__tb_sessions/checkpoints[/:id]`

**行为**：活跃会话消息数 ≥ 2 且为 10 的倍数时，写入最近 80 条消息检查点（含 goal/todos）；侧栏可确认后覆盖当前消息恢复。

**说明**：无多版本时间线，仅 latest。

## session-log-deepseek

- **分类**：会话 / 存储
- **作用**：DeepSeek 侧增量无损会话日志请求扩展。
- **状态**：部分就绪（本机 JSONL）
- **Lantern Harness 映射**：[`session-log-deepseek.mjs`](../lh-plugins/session-log-deepseek.mjs) → `POST /__tb_sessions/log` → `.local/session-log/<id>.jsonl`

**行为**：每轮对话成功结束后追加一行 `{ messages: [{role,content,reasoning_content?}] }`（DeepSeek 可回传形态）。

**说明**：非远端 DeepSeek 官方会话仓；仅本机增量备份，失败静默。

## session-persistence-jsonl

- **分类**：会话 / 存储

## session-query-sqlite

- **分类**：会话 / 存储
- **作用**：会话全文/结构化查询（sqlite）。
- **状态**：部分就绪（sqlite + JSON 回退）
- **Lantern Harness 映射**：[`session-query-sqlite.mjs`](../lh-plugins/session-query-sqlite.mjs) → `.local/session-query.sqlite`；`GET /__tb_sessions/query`；侧栏仍可用 [`session-query.ts`](../src/lib/session-query.ts) JSON 回退

**行为**：会话 PUT 时同步 sqlite 索引（标题+正文）；侧栏搜索优先走 sqlite LIKE，失败则线性扫 JSON。

**说明**：依赖 Node `node:sqlite`（22.5+）；CJK 用 LIKE（非 FTS5 分词）；不可用时自动回退 JSON。
