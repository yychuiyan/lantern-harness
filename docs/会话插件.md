# 会话插件

来源：[`src/lib/builtin-plugin-catalog.ts`](../src/lib/builtin-plugin-catalog.ts) 的 `SESSION_PLUGIN_CATALOG`（决策清单「做」）。

- **策略**：会话默认能力，无用户开关。
- **实现层**：目录展示 ≠ Cordis 包；会话已落地 Runner 在 [`builtin/session/`](../builtin/session/)；扩展/基建仍在 `lh-plugins/`。
- **与扩展关系**：扩展 Tab 为可开关产品能力（用例生成、记忆等）；`tool-web` / `tool-fs` 为会话内置，实现文件在 `builtin/session/`，不放在 `lh-plugins/`。
- **服务端回合**：[`session-runs.mjs`](../builtin/session/session-runs.mjs) 提供 `/__tb_sessions/runs`（start / SSE / stop）。有一体服务时 ChatApp 把回合放到进程内跑，刷新/切页可重连；手动停止展示「已停止」。无服务时降级浏览器流。

## agent-instructions

- **分类**：会话能力
- **作用**：加载 AGENTS.md/CLAUDE.md。
- **状态**：已就绪
- **Lantern Harness 映射**：`lh-fs` `/__tb_fs/agent-instructions` + ChatApp system 注入

**行为**：每次发送前（本地 dev + 工作区可用时）加载指令并并入 system。

**候选文件**（目录内按序、内容去重）：`AGENTS.md`、`CLAUDE.md`；可选 overlay：`AGENTS.local.md`、`CLAUDE.local.md`。

**作用域**：当前工作区目录 +（若不同）项目根 `projectRoot`；由宽到窄拼接。

**预算**：`maxBytes = 65536`；超限先丢更宽文件，再截断最具体文件。

**实现**：

- 在 [`builtin/session/lh-fs.mjs`](../builtin/session/lh-fs.mjs) 增加 `GET/POST /__tb_fs/agent-instructions`（读盘、截断、返回 `{ text, files[] }`）
- [`src/lib/fs-tools.ts`](../src/lib/fs-tools.ts) 增加 `fetchAgentInstructions()`
- [`ChatApp.tsx`](../src/components/islands/ChatApp.tsx) 在 `buildPluginMessages` 前拼入一段固定中文引导 + 正文（无文件则不加）

**边界**：无本地 fs / 无工作区：静默跳过，不报错打断发送。本批不做全局指令链、不做嵌套目录 touch 刷新。

## time-context

- **分类**：会话能力
- **作用**：注入当前时间与耗时。
- **状态**：已就绪
- **Lantern Harness 映射**：`src/lib/session-context.ts`（纯前端）

**行为**：每次发送前向 system 注入时钟上下文（纯前端，无需新 `tb-*`）。

**内容**：

- 当前时间（ISO 形态 + IANA 时区）
- 浏览器时区策略
- 距上一轮用户可见消息的耗时

**节流**：同一会话内默认最少间隔 **10 分钟**（`refreshIntervalMs: 600000`）；间隔内可注明沿用上次采样，避免每轮刷 system。

**实现**：新建 [`src/lib/session-context.ts`](../src/lib/session-context.ts)（`formatTimeContext` + 节流状态），由 ChatApp 写入 system 附加段。

**边界**：不写入 durable user 消息；不依赖 Cordis。

## tool-bash

- **分类**：会话能力
- **作用**：模型可调用 bash 在本机执行命令（默认同步；可 `background` 挂 jobs）。
- **状态**：已就绪
- **Lantern Harness 映射**：`lh-bash.mjs` / `bash-tools.ts`

**行为**：工具 `bash`：`command`（必填）、`workdir`（可选）、`background`（可选）。经 `/bin/bash -lc`（Windows 为 `bash`）。`background=true` 时立即返回 `jobId`。

**状态**：已就绪（会话默认；需本地服务；访问权限须为「工作区内修改」或「完全权限」）。

**Lantern Harness 映射**：

- Runner：[`builtin/session/lh-bash.mjs`](../builtin/session/lh-bash.mjs) → `/__tb_bash`
- 客户端：[`src/lib/bash-tools.ts`](../src/lib/bash-tools.ts)
- 同步：默认超时 30s（上限 120s）；stdout/stderr 各截断约 32KB
- 后台：见 [`tool-jobs`](#tool-jobs)

**边界**：软沙箱策略（命令黑名单 + 精简 env，非 OS 隔离）；持久会话见 `bash_session_*`（PTY 优先 / 管道回退）；无跨服务重启持久化；改文件优先 `fs_*`。

**持久会话**：`bash_session_open` / `exec` / `write` / `signal` / `read` / `close` / `list` → `/__tb_bash/session/*`（对齐全局 `persistent-bash` / `terminal-bash` / `pty`）。`write` 写 stdin（默认追加换行、不等待 prompt）；`signal` 支持 SIGINT/SIGTERM/SIGTSTP/SIGHUP。

## tool-fs-search

- **分类**：会话能力
- **作用**：模型可用 glob / grep 搜索工作区文件（内置 ripgrep）。
- **状态**：已就绪
- **Lantern Harness 映射**：`lh-fs` `/__tb_fs/glob`、`/__tb_fs/grep` + `fs_glob` / `fs_grep` 工具

**行为**：模型通过 `fs_glob` / `fs_grep` 搜索工作区（`glob` / `grep` 语义；工具名带 `fs_` 前缀以统一本仓库约定）。

**工具**：

- `fs_glob`：`pattern`（必填）、`path`（可选目录）；无 `/` 的 pattern 按任意深度匹配 basename；最多返回 100 条（mtime 新→旧）
- `fs_grep`：`pattern`（正则）、`path`（文件或目录）、`include`（可选 glob）；最多 250 条匹配

**实现**：

- [`builtin/session/lh-fs.mjs`](../builtin/session/lh-fs.mjs)：优先调用本机 `rg`，不可用时 Node 遍历回退
- [`src/lib/fs-tools.ts`](../src/lib/fs-tools.ts)：`FS_TOOLS_SEARCH`，随 `fsToolsForAccess` 一并注册（只读权限也可用）

**边界**：跳过 `node_modules` / `.git` / `dist` 等；不装 Cordis；不做 spill 完整结果落盘。

## tool-jobs

**边界**：进程内有效，重启本地服务后清空；不落盘；`bash` / `pwsh` 的 `background` 任务共用本注册表。

## tool-schedule

- **分类**：会话能力
- **作用**：模型可创建/查询/更新/删除定时提醒，到点投递回原会话。
- **状态**：已就绪
- **Lantern Harness 映射**：`schedule_create` / `schedule_list` / `schedule_update` / `schedule_cancel`

**行为**：

1. 模型用工具创建提醒（`dueAt` ISO 或 `delayMinutes`）
2. 本地服务在线时写入主机 `.local/schedules.json`（`/__tb_schedule`）；否则回退 `localStorage`（`tw-session-schedules`）
3. 主机约 15s tick：到期写入 `.local/sessions.json`；页面打开时每 10s `claim` / 合并，插入「⏰ 定时提醒：…」
4. 若浏览器已授权 Notification，同时弹出系统通知

**状态**：已就绪（会话默认；主机级见全局 `schedule`）。

**实现**：

- 主机：[`builtin/session/lh-schedule.mjs`](../builtin/session/lh-schedule.mjs)
- 客户端：[`src/lib/session-schedule.ts`](../src/lib/session-schedule.ts) + ChatApp

**边界**：无 Service Worker；主机投递依赖本地服务进程；消息带 `<!--tb-schedule:id-->` 去重。

## plan-mode

## present

- **分类**：会话能力
- **作用**：模型可声明「交付了哪些工作区文件」，便于 UI 展示/打开。
- **状态**：已就绪
- **Lantern Harness 映射**：`present` tool + `/__tb_fs/open` + 消息卡片

**行为**：模型工具 `present`，声明已存在的工作区交付文件，便于 UI 展示/打开。

**Tool schema**（）：

- `files`: `[{ path, description? }]`
- 单次最多 **4** 个；通常 1–2 个最重要交付物

**Runner**：校验路径在工作区策略内且为已存在普通文件（复用 `__tb_fs`）；失败返回明确错误。

**成功后**：挂到本轮助手消息 `presentFiles: { path, name, description? }[]`。

**UI**：复用 `caseFile` / `docsFile` 卡片样式；点击用 `POST /__tb_fs/open`（macOS `open` / Windows `start` / Linux `xdg-open`）打开本机文件。

**注册**：fs 能力开启时与 `fs_*` 一并加入 tools；system 中说明「交付物用 present，勿只嘴上说路径」。
