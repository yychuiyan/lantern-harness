# 业务地图功能与体验评估

评估更新日期：2026-11-21。范围为 `BusinessMapBoard.tsx`、`business-map.ts`、`lh-business-map.mjs` 与现有业务页样式。当前结论：手工维护与真实 AI 后台识别已接通，支持指定功能 / 多个功能 / 系统全量；流程稳定连接模型、版本快照与需求用例追溯仍需后续补充。

## 本次修复

- 入口与信息架构重构：卡片整体点击进入「系统概览」，移除卡片的设置和进入按钮；系统内统一「系统概览 / 功能目录 / 业务流程」导航，设置仅在顶部保留。
- 首页支持系统状态筛选、跨业务域 / 功能搜索与更新时间 / 名称排序；卡片呈现真实的功能 / 流程数与证据覆盖。
- 概览展示业务域结构、流程预览与待完善项，点击进入对应业务域、流程或维护状态筛选；移除原功能页重复的 AI 大提示与业务域卡片。
- 功能维护支持待确认 / 缺少证据 / 未关联流程组合筛选，空结果清空旧详情。证据覆盖仅代表记录存在，不代表证据已通过核验。

- 弹窗 portal 移出页面后丢失颜色变量，导致面板 / 输入框透明、边框消失。共享主题上下文并使用平台表面与边框变量，浅色、深色一致。
- 长表单正文滚动，弹窗与抽屉底部操作保持可见；AI / 发布抽屉使用 Dialog 统一 Esc、焦点约束和关闭回焦。
- 新增步骤不会被首步骤覆盖；按指定位置插入；默认参与系统使用当前系统名称。顺序调整时保留数字下一步的原目标；删除目标时清空引用。
- 流程名称、最终结果支持编辑；异常 / 实现说明可维护；异常分支可标记连接状态；列表点击重新打开已关闭的详情。
- 切换系统清除搜索与业务域，使用新系统的源码目录；保存功能保留未修改证据的 ID、备注和置信度。
- 发布检查同时阻止空流程与失效承载功能引用；新建步骤期间禁用不适用的上移 / 下移。
- 接通真实多来源采集与模型任务，低风险新功能自动入草稿，其他候选待审核；固定工单示例仅保留旧兼容接口。支持后台进度、取消、重试、跨空间隔离、引用校验与自动新增撤回。

## 优先补充：真实识别与业务闭环

1. **已接通：真实证据采集与模型分析。** 页面使用独立只读浏览器，文档读取选定正文，源码按范围扫描；结构化候选验证引用原文，至少两类来源且无冲突的低风险新功能自动入草稿。定向目标未识别、采集失败和达到限额均作为部分覆盖显示。当前没有定时巡检，扫描 PDF / OCR 和依赖写请求查询的页面仍有限制。
2. **P1：完整的流程连接模型。** 当前下一步和异常分支主要是自由文本，数字编号只能维护简单引用。建议改为稳定步骤 ID 与结构化分支条件，校验入口、结束节点、孤立节点和不可达分支；跨系统参与者应引用系统 ID，避免重命名失联。保留纵向阅读，按需增加分支预览。
3. **P1：需求 → 功能 → 流程 → 用例的追溯。** 目前角色、模块、规则和证据已经有字段，但需求、用例、缺陷仍缺少可导航关联。建议从已有内容库挑选对象而不是复制文本，并展示未覆盖功能、无证据功能、待确认规则。
4. **P1：发布快照与变更比较。** 当前发布记录主要是状态与 `publishedRevision`，尚无可恢复的版本快照。建议保存发布快照，区分草稿与已发布内容，展示差异、变更人、时间和回滚入口；不能把编号当作可恢复版本。

## 业务与 UI 优化建议

- **P1：结构化证据编辑。** 提案已支持字段差异与原文展开，后续将手动证据录入升级为结构化表单，替代竖线分隔文本。删除提案继续默认不勾选。
- **P1：未保存编辑保护。** 切换功能、系统、视图或关闭编辑时提示保存 / 放弃；本轮已完成可取消后台识别与实际进度恢复，剩余重点是手工编辑的离开保护。
- **P2：大型系统检索。** 本轮已补充角色关键词检索、待确认 / 缺少证据 / 未关联流程筛选及概览缺口定位；后续按真实数据规模增加模块分组、目录折叠和长列表优化。
- **P2：小屏完整导航。** 当前针对窄屏收紧布局并打开浮层详情；平台当前统一保留 1024px 最小桌面布局，小于该宽度允许页面横向滚动；后续可统一规划移动端，将左侧目录折叠为选择器，检查 390px 下的流程卡片、键盘导航与触摸目标。
- **P2：数据交换。** 提供带版本的 JSON 导入 / 导出与 Markdown 阅读视图，导入前预览差异和冲突；不直接覆盖现有空间数据。
