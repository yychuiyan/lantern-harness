# 安装手册

要求本地已安装 [Node.js](https://nodejs.org/)（需 22.22 及以上）。装好后在侧栏「设置」里配置模型 API Key（自带密钥，仅存本机）；默认地址 `http://127.0.0.1:4321/`。

## 方式一：本地服务（推荐）

### 1. 安装

```bash
npx lantern-harness
```

执行后会安装全局短命令 **`lantern`**。产品名 **Lantern Harness**；npm 包名 `lantern-harness`，命令 `lantern`。

- 升级：`lantern update`（最新版本）或 `lantern update <版本>`（指定版本）
- 卸载命令：`lantern uninstall`（保留数据空间）
- 查看可用版本：`lantern list`

### 2. 初始化数据空间

首次必做；可再次执行以更换数据空间：

```bash
lantern init
```

按序号选择：

```text
选择数据目录：
  1) 打开系统文件夹选择器
  2) 当前目录（当前终端所在位置）
  3) 自定义路径（手输）
请输入 1 / 2 / 3（默认 1）：
```

选项 `2` 的「当前目录」指执行命令时终端所在的工作目录（不是系统根 `/`，也不是固定的项目仓库根）。

选择结果记在本机（`lantern config` 可查看配置文件地址），供后续 `lantern web` 使用。若数据空间被移动/重命名/删除，请重新 `lantern init` 初始化或选择已有数据空间。

### 3. 常用命令

```bash
lantern init           # 选择并记住数据空间
lantern web            # 启动本地 Web 服务
lantern stop           # 停止服务
lantern restart        # 重启服务
lantern status         # 运行状态、端口、数据空间
lantern open           # 在浏览器中打开工作台
lantern path           # 显示当前数据空间路径
lantern config         # 显示配置文件地址
lantern logs           # 查看服务日志
lantern doctor         # 检查运行环境与配置是否正常
lantern help           # 显示操作命令列表
lantern version        # 显示当前版本号
lantern list           # 显示可用版本列表
lantern update         # 更新到最新版本
lantern update 0.1.x   # 更新到指定版本
lantern uninstall      # 卸载本机 lantern 命令（保留数据空间）
lantern wipe           # 删除当前数据空间（需确认；不可恢复）
lantern ask            # 进阶：无界面单轮问答，lantern ask <提示词>
lantern rpc            # 进阶：以 stdio JSON-RPC 暴露本地问答能力
lantern acp            # 进阶：以 ACP 子集供外部编排驱动无 UI Agent
```

### 4. 打开工作台

浏览器打开终端提示的地址（或 `lantern status` / `lantern open`），在侧栏「设置」配置模型即可。

### 5. 首次进入看到什么

新建空间默认开启「提示词管理」，其余插件默认关闭，所以侧栏只有「我的工作台」「提示词管理」「帮助中心」三项。每个空间都会自动带上自己的「默认提示词.md」，可随时在「提示词管理」或「空间管理 → 编辑」中修改。需要用例 / 知识库 / 任务 / 待办 / 记忆 / 插件开发等入口时，进入「插件」页在「扩展插件」里按分类开启：

| 分类       | 插件                                         | 新建空间默认 |
| ---------- | -------------------------------------------- | ------------ |
| 内容库     | 用例管理、知识库管理、需求文档库、测试模板库 | 关           |
| 内容库     | 提示词管理                                   | 开（内置）   |
| 生成能力   | 生成测试用例、生成提示词、生成知识库         | 关           |
| 记忆与检索 | 知识库检索、会话记忆                         | 关           |
| 待办与效率 | 任务管理、待办事项                           | 关           |
| 开发工具   | 插件开发                                     | 关           |

## 方式二：源码启动

适合改代码或二次开发。

### 1. 克隆仓库

```bash
git clone https://github.com/yychuiyan/lantern-harness.git
cd lantern-harness
```

### 2. 开发模式

热更新，含本地落盘 API：

```bash
pnpm install
pnpm dev
```

### 3. 预览静态页

需先打包；无本地落盘：

```bash
pnpm build
pnpm preview
```

更完整的产品用法见 [操作手册](https://lantern.yychuiyan.com/docs/manual/)。
