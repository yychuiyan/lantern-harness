# 功能用例转 UI 自动化

## 适用范围

用于从功能测试用例中提取 UI 自动化范围。功能用例仍是业务事实来源；本技能只做可自动化评估、用例拆分和 UI Plan 设计。

## 流程

1. 读取用户明确选择的功能用例行，以及所选 UI 自动化项目的框架、地址和迭代文件。
2. 逐条判断 `automatable`、`needs_manual` 或 `not_automatable`，说明依据和风险。
3. 只对可自动化条目生成自动化用例：前置条件、可执行步骤、可观察预期和最小 UI Plan。
4. 校验 Plan 动作、断言、环境变量占位和敏感信息。
5. 用户确认后，由平台写入自动化用例文件、创建待探索 UI 自动化会话并绑定项目与 iteration 文件。

## 约束

- 不生成 CSS、XPath、坐标、定位器或脚本代码。
- 不把接口、性能、数据库、App 原生操作误判为 UI 自动化。
- 不修改原功能用例，不覆盖人工执行结果。
- 不自动开始浏览器探索、写项目或运行脚本。
- 一个功能用例可拆成多个自动化用例；每条自动化用例必须有唯一稳定 ID。
- 目标脚本最终合并到项目现有 `tests/iteration/<迭代>.spec.ts`，而不是独立 spec。
