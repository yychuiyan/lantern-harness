# Lantern 缺陷提交

1. 先调用 `lantern_defect_templates` 列出规则。按用户指定的规则调用 `lantern_defect_template_select`，多份规则且用户未指定时询问选择。已有选定规则时可直接使用。调用 `lantern_defect_context` 获取当前空间的缺陷入口、规则、映射字段和可用选项。插件停用或尚未配置时，引导用户在 Lantern「插件仓库 → 测试技能」开启「缺陷规则」。用户明确要求维护缺陷规则时，先用 `lantern_defect_rule_inspect` 读取真实入口、子表和字段，再用 `lantern_defect_rule_save` 保存；删除规则前必须获得用户明确确认并使用 `lantern_defect_rule_delete`。使用上下文返回的规则，避免把具体团队的规则硬编码在 Skill 中。
2. 用描述、截图或日志中有依据的事实生成结构化缺陷。以字段 ID 作键。每个字段的 `rule` 是必须执行的判断或生成口径：严重程度、优先级等需要判断的字段，只要 `rule` 提供了判断标准，就应按标准分析问题影响并说明依据，不能仅因需要判断而留空或要求用户决定。`defaultValue` 是规则默认值，只在没有用户值、材料证据或可执行 `rule` 结果时兜底；本次输入或材料明确提供其他值时优先使用本次值。选项和关联字段使用当前平台上下文要求的稳定标识（例如选项 ID、成员 ID、issue key 或 bug ID），多值使用标识数组。规则上下文包含 `iteration` 时，目标字段「迭代版本」必须直接使用这个当前迭代，不再向用户重复询问，也不能被其他来源覆盖。图片字段先用目标平台的上传能力取得 image ID，再传 image ID 数组；附件字段只有在连接器明确支持上传和回写时填写，否则保持为空，不能把本地路径或普通文本写进附件字段；非必填的图片 / 附件没有材料时直接留空，不阻塞提交。通用规则若引用其他文档、知识库页面或目标平台记录，必须先通过当前空间可用且与目标平台匹配的工具读取并核对其中的项目、测试分项目、经办人、迭代等事实；通用规则给出的业务映射优先于常识推断，例如指定经办人归前端、其他经办人归后端时，应先匹配真实经办人，再填写测试项目和测试分项目，空白或无关人员不能自动算作“其他”。负责人、迭代、需求关联等缺少可匹配事实时不能猜；确实无法按 `rule` 和现有证据判断的其他字段应留空或说明待确认。
3. 整理「重现步骤」时，操作动作与前置内容分开：账号密码、登录账号、权限、特定数据准备等不属于操作步骤的内容，要放到操作步骤之后的「前置条件：」小节，并以 `1.`、`2.` 逐条编号；没有前置条件时不添加该小节，不能编造账号密码。
4. 需要恢复未完成工作时，先调用 `lantern_defect_drafts` 查看当前空间的草稿与状态，避免重复新建。调用 `lantern_defect_draft_save`，传入上下文 `revision` 作为 `contextRevision`。未传入的字段由服务端套用规则默认值。编辑草稿时也传上次返回的草稿 `id` 和草稿 `revision`。如有版本冲突，重新读上下文并检查用户意图。
5. 按用户意图处理保存后的草稿：「生成缺陷」「先做个草稿」「预览后再提交」只保存并展示目标、完整非空字段和 `missing`，不提交。用户说「提个缺陷」「提交缺陷」「录入缺陷」等明确要求最终提交的表达，就是授权直接提交：保存草稿后应在同一轮立即用该草稿的 `id` 和 `revision` 调用 `lantern_defect_submit`，不要再要求用户二次确认。只有必填字段缺失、目标有歧义，或负责人、迭代、需求关联等关键字段无法从证据匹配时才停下来说明。修改用户已确认的草稿后应重新提交核验。对于 `platform: manual` 的入口，提供可复制的缺陷正文和目标入口。
6. 只有返回 `status: submitted` 才报告成功，并附缺陷编号、目标入口和记录标识（如 record_id、issue key 或 bug ID）。返回 `pending` 时用 `lantern_defect_receipt` 核验同一草稿。没有记录标识时说明需人工核对目标平台，不能重提或新建草稿来绕过。

每个字段的 rule 是该字段的填写要求，defaultValue 是与填写要求分离的规则默认值。手动规则可以尚无目标入口，使用时按用户输入确定目标并通过远端真实字段核对。包含手动字段的规则通过工作台或与目标平台匹配的连接器解析和执行，不使用旧版直接提交工具猜测列名。目标平台可能是腾讯文档、JIRA、禅道或其他已连接系统，必须按任务中的 platform 选择工具，不能默认走腾讯文档。
